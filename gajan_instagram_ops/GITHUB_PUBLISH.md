# Publish to GitHub

1. Create a new **private** empty GitHub repository named `gajan-instagram-operations`. Do not initialize with a README. Confirm you are permitted to upload this confidential take-home.
2. From this directory run:

```bash
git init
git add .
git commit -m "Initial compliant Instagram operations prototype"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/gajan-instagram-operations.git
git push -u origin main
```

3. Give the client access to the private repository and share the link.

**Never commit** a real database, credentials, vault secrets, customer data, backup codes, or company-only access details. The provided reports are synthetic demonstration data.
